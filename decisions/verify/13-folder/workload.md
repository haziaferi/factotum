## Requirements this adds to Factotum, whatever the layout

1. **Firing writes nothing that syncs.** Fire bookkeeping (`nextFireAt`, `lastFiredAt`, nag counters) is device state. Occurrences are computed from the rule (ADR 04), not stored.
2. **Folder exports are debounced.** The database may be written on every keystroke, as Tendril does. The folder must not be.
3. **Every folder write replaces a file atomically** (temp file, then rename). Where SAF cannot do that, the reader must tolerate a torn file.
4. **Compact JSON, never pretty-printed,** in files that sync.
5. **The device-id file is excluded from Android Auto Backup and device transfer.** Otherwise two devices share an identity, under every layout.
