T1.8 toasts and dialogs: score tables

Every variant scored by python tools/screens/toast_opt.py, from drawings measured in headless Edge (360×740 phone, 1100×660 Windows). Axes are rank sums within a part, lower is better; ★ marks the Pareto front; each part's control (italics, dashed rule) was built to lose, and the run fails if it reaches the front. Grey rows failed the gate (a target under 48 dp).

Reference distance joins the axes once the reference apps are captured (toast-references.json).

How this page is kept (owner, 2026-10-17): the newest pass first. A part still open shows its front and its control; a picked part shows only its picks; a part replaced by a later pass, or discarded, is one line naming the commit that last scored it, which holds every score (its JSON record left the folder, owner 2026-10-26). Nothing replaced is drawn.
