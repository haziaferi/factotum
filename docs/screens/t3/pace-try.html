Paced timer: try the sheets

The four sheets with the best totals in T3b.4, re-scored after the Consistency fix (When's sentence covers the run, not the pauses), and Break Down Timer as the control that must lose. Choose a sheet, choose a task, press Begin, then do the task on the phone. Every tap inside the phone is counted. Start checks the run against the task: a wrong Start counts as an error and says what differs (a pause may be half a minute off). Fixes count ⌫, deleted pauses, and a value set again. It is 13:00 in every task; runs 1–3 are the scored walk's, and a blank sheet starts at 45 min. The sheets follow the When sheet's pattern: Cancel, the title and Start on top; the sentence pinned at the foot; each chooser (keypad, list, grid, the line) opening above it, so the sheet grows upward only while one is open. Undo and Redo count as fixes. Where the timer lives while it runs is scored separately (T3b.4b).
