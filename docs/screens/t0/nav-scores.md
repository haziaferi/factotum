# Navigation candidates, scored

Generated by `tools/screens/nav_score.py`. The inputs are:

- the owner's cadences (`jobs.md`);
- the reference survey (`reference.md`);
- each candidate's per-job costs, listed below so every one can be challenged.

**How each objective is computed**

- **Weekly cost** is Σ weight × steps over the sought jobs, with half a step added when a job is not reachable from anywhere. Lower is better.
- **Fixed** is the number of navigation entries always on screen.
- **Start load** is the number of zones on the start screen.
- **Register** is 1 when no default surface mixes modules of different tone. Lower is worse.

Weights per week: 35 for several a day, 7 for daily, 2 for when noticed, 1 for weekly. Rare jobs are 0.25, an assumption.

**Layouts:**

- **A. Module tabs**: Bar/rail: Today · Habits & tracking · Check-in · Pages · More. Search icon in every header (Ctrl+K on Windows); capture FAB on Today, a global quick-add hotkey on Windows.
- **B. Today hub**: Start = Today hub in zones: agenda, routines due (habits, readings, checklists, timers), the journal card, a check-in prompt. Bar: Today · Calendar · Pages · Review. Capture FAB everywhere; search in every header.
- **C. Time + cadence**: Bar: Today · Week · Journal & pages · Review. Today = agenda + routines due. A global + offers capture and check-in (with ledger and sensory inside the check-in). Journal & pages opens on today's journal.
- **D. Action bar + tree**: Bar: Search · Capture · Menu (Obsidian/Notion). Start = the tree; modules and pages are tree entries, Today pinned first; the menu holds the daily actions.
- **E. Tendril (control)**: Tendril as it ships: Pages · Calendar · Tasks & Habits · Road Map · Settings; Ctrl+K and a quick-add window on Windows only.
- **F. Hybrid: time bar + smart + (journal first)**: Phone bar: Today · Week · [+] · Library · Review; Windows rail the same with Ctrl+1..4, Ctrl+K search and a system-wide quick-add hotkey. Today = agenda + routines due, all logged in place. [+] = one natural-language line with chips (task/event/reminder, note, reading, timer, check-in, sensory, ledger). Library opens on today's journal, the page tree one tap below. Search in every header.
- **G. Hybrid: time bar + smart + (tree first)**: As F, but Library opens on the page tree with today's journal pinned first.
- **H. Hybrid: hub zones + time bar + smart +**: As F, but Today also carries the journal card and a check-in prompt, as zones (B's hub on F's frame).
