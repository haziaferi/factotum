Every variant scored by python tools/screens/toast_opt.py, from drawings measured in headless Edge (360×740 phone, 1100×660 Windows). Axes are rank sums within a part, lower is better; ★ marks the Pareto front; each part's control (italics, dashed rule) was built to lose, and the run fails if it reaches the front. Grey rows failed the gate (a target under 48 dp).

Reference distance joins the axes once the reference apps are captured (t2-refs.json).
