# Factotum

## How changes land

Changes reach `main` through a pull request. Pick the merge method per PR:

- **Squash** by default, for feature and fix PRs.
- **Rebase-merge** when each commit was deliberately kept clean and self-contained.
- **Merge commit** only to sync branches, never for feature work.

GitHub allows all three methods on this repository, and no ruleset enforces one, so the choice is made per PR.
